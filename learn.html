    Your first programİlk programın
    
                
    5 minutes · printing text to the screen5 dakika · ekrana yazı yazdırmak
    
              
    
            
    
            
    
              A program is a list of instructions that the computer follows from top to bottom. Our first instruction is the most famous one in programming: show some text on the screen.
              Program, bilgisayarın yukarıdan aşağıya sırayla uyguladığı komutlardan oluşur. İlk komutumuz programlamanın en ünlü komutu: ekrana bir yazı yazdırmak.
            
    
            
    
              In Java, every program lives inside a class and starts running from a method called main. For now you can treat these lines as a frame that you copy every time: public class Main and public static void main(String[] args). We will understand each word later. The printing instruction is System.out.println(...), and every instruction ends with a semicolon ;.
              Java'da her program bir sınıfın (class) içinde yaşar ve main adlı bir metottan çalışmaya başlar. Şimdilik bu satırları her seferinde kopyaladığın bir çerçeve gibi düşün: public class Main ve public static void main(String[] args). Her kelimenin anlamını ilerleyen derslerde göreceğiz. Yazdırma komutu System.out.println(...); her komut bir noktalı virgülle ; biter.
            
    
            
    
              Python has no frame at all: a single line, print(...), is a complete program. There are no semicolons either; each line is one instruction.
              Python'da hiç çerçeve yok: tek bir satır, print(...), başlı başına bir programdır. Noktalı virgül de yok; her satır bir komuttur.
            
    
            
    
            
      
              
    • println moves to a new line after printing, while print stays on the same line. In Python, print always adds a new line unless you write end="".println yazdıktan sonra alt satıra geçer, print aynı satırda kalır. Python'da print her zaman alt satıra geçer; geçmemesi için end="" yazarsın.
      • 
              
    • Text goes between double quotes: "Hello". The quotes themselves are not printed.Yazılar çift tırnak içine yazılır: "Merhaba". Tırnakların kendisi ekrana yazılmaz.
      • 
              
    • Lines that start with // in Java or # in Python are comments: notes for humans that the computer skips.Java'da //, Python'da # ile başlayan satırlar yorumdur: bilgisayarın atladığı, insanlar için yazılmış notlar.
      • 
            
    
            
    
              
              
    Capital letters matter. Both languages are case-sensitive: system.out.println or Print("hi") will not work. If Java says ';' expected, you forgot a semicolon at the end of the line.Büyük-küçük harf önemli. İki dil de büyük-küçük harfe duyarlıdır: system.out.println ya da Print("selam") çalışmaz. Java ';' expected diyorsa satırın sonuna noktalı virgül koymayı unutmuşsun demektir.

    Variables and data typesDeğişkenler ve veri türleri
    
                
    8 minutes · storing values8 dakika · değer saklamak
    
              
    
            
    
            
    
              A variable is a name you give to a value so you can use it later. Think of a labelled box: the label is the name, and the thing inside is the value.
              Değişken, bir değeri sonra kullanabilmek için ona verdiğin isimdir. Üzerinde etiket olan bir kutu düşün: etiket ismi, içindeki şey de değeridir.
            
    
            
    
              In Java you say what type of value the box will hold when you create it: int age = 21;. Python works out the type from the value, so you just write age = 21. Once a box exists, you can put a new value in it: age = age + 1.
              Java'da kutuyu oluştururken içinde hangi türde değer duracağını söylersin: int yas = 21;. Python türü değerden kendisi anlar; sadece yas = 21 yazarsın. Kutu bir kez oluşunca içine yeni bir değer koyabilirsin: yas = yas + 1.
            
    
            
    
              
    
                
    Kind of valueDeğer türüJavaPython
    
                
                  
    Whole numberTam sayıint score = 90;score = 90
    
                  
    Decimal numberOndalıklı sayıdouble price = 9.99;price = 9.99
    
                  
    TextMetinString city = "Sydney";city = "Sydney"
    
                  
    True / falseDoğru / yanlışboolean done = true;done = True
    
                  
    Single characterTek karakterchar grade = 'A';a 1-letter text: "A"1 harflik metin: "A"
    
                    
              
    
            
    
            
    
            
    
              To join text and numbers, Java simply uses +: "Age: " + age. In Python, + only joins text to text, so you either convert with str(age), pass several values to print separated by commas, or use an f-string: f"Age: {age}".
              Metinle sayıyı birleştirmek için Java doğrudan + kullanır: "Yaş: " + yas. Python'da + sadece metni metinle birleştirir; bu yüzden ya str(yas) ile çevirirsin, ya print'e virgülle birden fazla değer verirsin ya da bir f-string kullanırsın: f"Yaş: {yas}".
            
    
            
    
              
              
    Java keeps you to your word. If you declared int age, you cannot later store text in it: age = "twenty"; is a compile error (incompatible types). Python allows it, but changing a variable's type usually just causes confusion. Also note: Java writes true, Python writes True.Java sözünü tutturur. int yas dediysen sonra içine metin koyamazsın: yas = "yirmi"; derleme hatasıdır (incompatible types). Python buna izin verir ama bir değişkenin türünü değiştirmek genelde sadece kafa karıştırır. Bir de: Java true, Python True yazar.
    
            
    
            
    
              
              
    Naming. Java style is studentCount (camelCase), Python style is student_count (snake_case). Names cannot start with a digit or contain spaces. Pick names that say what is inside: price beats x.İsimlendirme. Java tarzı ogrenciSayisi (camelCase), Python tarzı ogrenci_sayisi (snake_case). İsimler rakamla başlayamaz ve boşluk içeremez. İçinde ne olduğunu söyleyen isimler seç: fiyat, x'ten iyidir.

    Math and operatorsMatematik ve operatörler
    
                
    8 minutes · calculating with code8 dakika · kodla hesap yapmak
    
              
    
            
    
            
    
              Computers are very fast calculators. The symbols are the ones you know from school, with one big surprise in division.
              Bilgisayarlar çok hızlı hesap makineleridir. İşaretler okuldan bildiklerin; yalnız bölmede büyük bir sürpriz var.
            
    
            
    
              
    
                
    OperationİşlemJavaPython
    
                
                  
    Add, subtract, multiplyTopla, çıkar, çarp+ - *+ - *
    
                  
    DivideBöl7 / 2 → 3  ·  7 / 2.0 → 3.57 / 2 → 3.5
    
                  
    Whole-number divisionTam bölme7 / 2 → 37 // 2 → 3
    
                  
    Remainder (modulo)Kalan (mod)17 % 5 → 217 % 5 → 2
    
                  
    PowerÜsMath.pow(2, 10) → 1024.02 ** 10 → 1024
    
                  
    Add to a variableDeğişkene eklex += 5;   x++;x += 5 (no ++)(++ yok)
    
                    
              
    
            
    
            
    
              The division trap: in Java, when you divide two whole numbers the answer is also a whole number, and the decimal part is simply thrown away. 7 / 2 is 3, not 3.5. To get 3.5, at least one side must be a decimal: 7 / 2.0 or (double) 7 / 2. Python always gives the real answer with / and has a separate // for whole-number division.
              Bölme tuzağı: Java'da iki tam sayıyı bölersen sonuç da tam sayı olur ve küsurat basitçe atılır. 7 / 2 sonucu 3'tür, 3.5 değil. 3.5 almak için iki taraftan en az biri ondalıklı olmalı: 7 / 2.0 ya da (double) 7 / 2. Python / ile her zaman gerçek sonucu verir, tam bölme için ayrıca // vardır.
            
    
            
    
              The remainder operator % is more useful than it looks: n % 2 == 0 tells you whether a number is even, and minutes % 60 gives the minutes left over after taking out whole hours. Just like in school, * and / happen before + and -; use brackets when you want a different order.
              Kalan operatörü % göründüğünden faydalıdır: n % 2 == 0 bir sayının çift olup olmadığını söyler, dakika % 60 tam saatler çıktıktan sonra kalan dakikayı verir. Okuldaki gibi * ve /, + ve -'den önce yapılır; farklı bir sıra istiyorsan parantez kullan.
            
    
            
    
            
    
              
              
    Brackets when joining text. In Java "Total: " + 2 + 3 prints Total: 23, because the text is joined first, from left to right. Write "Total: " + (2 + 3) instead. Also, Java's int has a limit (about 2.1 billion); go past it and the number wraps around to a negative value. Python's whole numbers have no limit.Metin birleştirirken parantez. Java'da "Toplam: " + 2 + 3 ekrana Toplam: 23 yazar; çünkü soldan sağa önce metin birleştirilir. Bunun yerine "Toplam: " + (2 + 3) yaz. Bir de, Java'nın int türünün bir sınırı var (yaklaşık 2,1 milyar); aşarsan sayı başa dönüp eksi bir değere düşer. Python'un tam sayılarında sınır yoktur.

    Getting input from the userKullanıcıdan girdi almak
    
                
    10 minutes · Scanner and input()10 dakika · Scanner ve input()
    
              
    
            
    
            
    
              Programs get interesting when they talk back. Let's ask the user a question and answer with what they typed.
              Programlar karşılık verdiğinde eğlenceli hale gelir. Kullanıcıya bir soru soralım ve yazdığı şeyle cevap verelim.
            
    
            
    
              Java reads the keyboard with a tool called Scanner. You bring it in with import java.util.Scanner; at the very top, create one with new Scanner(System.in), then ask it for the next value: nextLine() reads a whole line of text, nextInt() reads a whole number and nextDouble() reads a decimal number.
              Java klavyeyi Scanner adlı bir araçla okur. En üste import java.util.Scanner; yazarak onu programa dahil eder, new Scanner(System.in) ile bir tane oluşturur, sonra sıradaki değeri istersin: nextLine() bütün bir satırı metin olarak, nextInt() bir tam sayıyı, nextDouble() ondalıklı bir sayıyı okur.
            
    
            
    
              Python has one function, input(). It can show a question too, input("Your name? "), and it always gives back text. When you need a number, convert it: int(input()) or float(input()).
              Python'da tek bir fonksiyon var: input(). Soruyu da kendisi gösterebilir, input("Adın? "), ve her zaman metin döndürür. Sayı gerekiyorsa çevirirsin: int(input()) ya da float(input()).
            
    
            
    
              
              
    Try it: press Run. When the program asks a question, a line with a gold › appears in the console. Type your answer there and press Enter.Dene: Çalıştır'a bas. Program soru sorduğunda konsolda altın renkli bir › satırı belirir. Cevabını oraya yaz ve Enter'a bas.
    
            
    
            
    
            
    
              
              
    
                
    Java's famous trap: after nextInt(), a following nextLine() returns an empty text. nextInt() reads the number but leaves the Enter behind, and nextLine() picks up that empty rest of the line. Fix it by adding an extra sc.nextLine(); after nextInt(), or read everything with nextLine() and convert with Integer.parseInt(...).Java'nın meşhur tuzağı: nextInt()'ten sonra gelen bir nextLine() boş metin döndürür. nextInt() sayıyı okur ama Enter'ı geride bırakır; nextLine() da satırın o boş kalan kısmını alır. Çözüm: nextInt()'ten sonra fazladan bir sc.nextLine(); ekle ya da her şeyi nextLine() ile okuyup Integer.parseInt(...) ile çevir.
    
                
    Python's trap: input() is text, so input() + 1 crashes with a TypeError. Convert first: int(input()) + 1.Python'un tuzağı: input() metindir; bu yüzden input() + 1 bir TypeError ile çöker. Önce çevir: int(input()) + 1.

    Making decisions: if and elseKarar vermek: if ve else
    
                
    10 minutes · conditions and comparisons10 dakika · koşullar ve karşılaştırmalar
    
              
    
            
    
            
    
              Now the program can think: if something is true it does one thing, otherwise it does something else.
              Artık program düşünebilir: bir şey doğruysa bir iş yapar, değilse başka bir iş.
            
    
            
    
              A condition is a question whose answer is true or false, such as age >= 18. You compare with == (equal), != (not equal), <, >, <= and >=. Note the double ==: a single = means "put this value in the box".
              Koşul, cevabı doğru ya da yanlış olan bir sorudur; örneğin yas >= 18. Karşılaştırmak için == (eşit), != (eşit değil), <, >, <= ve >= kullanırsın. Çift =='ye dikkat: tek = "bu değeri kutuya koy" demektir.
            
    
            
    
              
    
                
    JavaPython
    
                
                  
    ShapeYazılışif (x > 0) { ... }if x > 0: + indented lines+ girintili satırlar
    
                  
    Another checkBaşka bir kontrolelse if (...) { ... }elif ...:
    
                  
    OtherwiseDeğilseelse { ... }else:
    
                  
    and / or / notve / veya / değil&&  ||  !and  or  not
    
                    
              
    
            
    
            
    
              Java groups the lines that belong to an if with curly braces { }. Python uses indentation instead: every line that is pushed four spaces to the right after the colon belongs to the if. Only the first true branch runs, so the order of your checks matters.
              Java bir if'e ait satırları süslü parantezle { } gruplar. Python bunun yerine girinti kullanır: iki noktadan sonra dört boşluk sağa itilmiş her satır o if'e aittir. Sadece doğru olan ilk dal çalışır; bu yüzden kontrollerin sırası önemlidir.
            
    
            
    
            
    
              
              
    
                
    Comparing text in Java: do not use == for Strings. It checks whether two variables point to the very same object, so with text typed by the user it often says false even when the words match. Use answer.equals("yes") (or equalsIgnoreCase). In Python, == works correctly for text.Java'da metin karşılaştırma: String'ler için == kullanma. == iki değişkenin aynı nesneyi gösterip göstermediğine bakar; kullanıcının yazdığı metinde kelimeler aynı olsa bile çoğu zaman false der. cevap.equals("evet") (ya da equalsIgnoreCase) kullan. Python'da == metinler için doğru çalışır.
    
                
    A stray semicolon: if (x > 5); ends the if right there, and the block after it always runs. In Python, a missing indent gives an IndentationError.Fazla noktalı virgül: if (x > 5); if'i orada bitirir ve sonraki blok her zaman çalışır. Python'da eksik girinti IndentationError verir.

    Loops: for and whileDöngüler: for ve while
    
                
    12 minutes · repeating work12 dakika · işi tekrarlamak
    
              
    
            
    
            
    
              Instead of writing the same line a hundred times, we tell the computer: "do this a hundred times".
              Aynı satırı yüz kez yazmak yerine bilgisayara "bunu yüz kez yap" deriz.
            
    
            
    
              A for loop is for when you know how many times to repeat. Java's version has three parts in brackets: where to start (int i = 1), when to keep going (i <= 5) and what to change after each round (i++). Python walks through a range: for i in range(1, 6): gives 1, 2, 3, 4, 5. The end number of a range is not included.
              for döngüsü kaç kez tekrarlanacağını bildiğinde kullanılır. Java'nın for'unda parantez içinde üç parça vardır: nereden başlanacağı (int i = 1), ne zamana kadar süreceği (i <= 5) ve her turdan sonra neyin değişeceği (i++). Python bir range boyunca yürür: for i in range(1, 6): 1, 2, 3, 4, 5 verir. range'in bitiş sayısı dahil değildir.
            
    
            
    
              A while loop repeats as long as its condition is true; use it when you do not know the number of rounds in advance, like "keep asking until the password is right". Inside any loop, break leaves the loop immediately and continue skips to the next round.
              while döngüsü koşulu doğru olduğu sürece tekrarlar; tur sayısını önceden bilmediğinde kullanılır, örneğin "şifre doğru olana kadar sormaya devam et".     Classes and objectsSınıflar ve nesneler
    
                
    15 minutes · object-oriented programming15 dakika · nesne yönelimli programlama
    
              
    
            
    
            
    
              A class is a blueprint and an object is something built from it. "Student" is a class; "Ayşe, 20 years old" is an object made from that class.
              Sınıf bir kalıptır, nesne ise o kalıptan üretilen şeydir. "Öğrenci" bir sınıftır; "Ayşe, 20 yaşında" o sınıftan üretilmiş bir nesnedir.
            
    
            
    
              A class bundles data (fields such as name and age) with behaviour (methods such as addGrade). The constructor runs when a new object is created and fills in its fields. In Java it has the same name as the class, and this.name = name means "this object's name is the name I was given". In Python the constructor is always called __init__, and the object refers to itself as self.
              Sınıf verileri (isim, yaş gibi alanlar) ve davranışları (notEkle gibi metotlar) bir araya getirir. Yapıcı (constructor) yeni bir nesne oluşturulurken çalışır ve alanlarını doldurur. Java'da sınıfla aynı adı taşır; this.isim = isim "bu nesnenin ismi bana verilen isimdir" demektir. Python'da yapıcının adı her zaman __init__'tir ve nesne kendinden self diye bahseder.

And about static: a static method belongs to the class itself, while a normal method belongs to each object and can use its fields.private ve getter'lar. Java'da alanlar genelde private olur; böylece başka sınıflar onları doğrudan değiştiremez, getIsim() gibi metotlardan geçmek zorunda kalır. Buna kapsülleme (encapsulation) denir. Python'da private yoktur; gelenek olarak başına alt çizgi koymak, _isim, "lütfen dışarıdan dokunma" anlamına gelir. static'e gelince: static bir metot sınıfın kendisine aittir; normal bir metot ise her nesneye aittir ve onun alanlarını kullanabilir.

    Errors and exceptionsHatalar ve hata yakalama
    
                
    12 minutes · reading errors, try and catch12 dakika · hataları okumak, try ve catch
    
              
    
            
    
            
    
              Error messages are not your enemy; they are directions. They tell you where the problem is and what kind of problem it is.
              Hata mesajları düşmanın değil, yol tarifidir. Sorunun nerede olduğunu ve ne tür bir sorun olduğunu söylerler.
            
    
            
    
              There are two kinds of errors. Compile errors are found before the program runs: a missing semicolon, a typo in a name, text put into an int. Java checks the whole program first, so it finds many of these early. Runtime errors (exceptions) happen while the program is running: dividing by zero, a list position that does not exist, converting "abc" into a number. In Python almost everything is found at runtime, except syntax errors.
              İki tür hata vardır. Derleme hataları program çalışmadan önce bulunur: eksik noktalı virgül, bir isimde yazım hatası, int'e konmuş metin. Java önce bütün programı kontrol eder; bu yüzden bunların çoğunu erkenden yakalar. Çalışma zamanı hataları (exception) program çalışırken olur: sıfıra bölmek, olmayan bir liste konumu, "abc"'yi sayıya çevirmek. Python'da sözdizimi hataları dışında neredeyse her şey çalışırken bulunur.
            
    
            
    
              How to read one: look for the line number and the error name. Main.java:5: error: ';' expected means line 5 is missing a semicolon. ZeroDivisionError: division by zero on line 3 means you divided by zero there. On this page, every error also gets a short explanation in plain words under the console.
              Nasıl okunur: satır numarasına ve hatanın adına bak. Main.java:5: error: ';' expected, 5. satırda noktalı virgül eksik demektir. line 3 üzerinde ZeroDivisionError: division by zero, orada sıfıra böldün demektir. Bu sayfada her hatanın altında, konsolun hemen altında sade bir açıklama da çıkar.
            
    
            
    
              You can catch runtime errors so the program does not crash: Java uses try { ... } catch (SomeException e) { ... }, Python uses try: ... except SomeError: .... The finally part runs either way. You can also raise your own error with throw new IllegalArgumentException("...") or raise ValueError("...").
              Programın çökmemesi için çalışma zamanı hatalarını yakalayabilirsin: Java try { ... } catch (BirException e) { ... }, Python try: ... except BirError: ... kullanır. finally kısmı her durumda çalışır. Kendi hatanı da fırlatabilirsin: throw new IllegalArgumentException("...") ya da raise ValueError("...").

Breaking code on purpose is one of the fastest ways to learn what messages mean.Deney yap: örneği çalıştır ve abc yaz; sonra 0 ve 4 ile tekrar çalıştır.     When you want to code on your own computer, install a JDK (for example Temurin) and an editor such as IntelliJ IDEA or VS Code for Java, and Python from python.org for Python.Kendi bilgisayarında kod yazmak istediğinde Java için bir JDK (örneğin Temurin) ve IntelliJ IDEA ya da VS Code gibi bir editör, Python için python.org'dan Python kurabilirsin.
    
            
    
          
    
          
    
            Is the Java on this page real Java?Bu sayfadaki Java gerçek Java mı?
            
    
              
    The Python is real Python (CPython compiled to WebAssembly, called Pyodide). The Java runs on a small interpreter written for this page that understands the Java a beginner writes: variables and types, if/switch, loops, arrays, String and Math, Scanner, ArrayList, HashMap, classes, inheritance, interfaces, enums and exceptions. It also shows the same error messages as the real Java compiler.Python gerçek Python'dur (WebAssembly'ye derlenmiş CPython, adı Pyodide). Java ise bu sayfa için yazılmış küçük bir yorumlayıcıda çalışır ve yeni başlayanların yazdığı Java'yı anlar: değişkenler ve türler, if/switch, döngüler, diziler, String ve Math, Scanner, ArrayList, HashMap, sınıflar, kalıtım, arayüzler, enum'lar ve hatalar. Hata mesajları da gerçek Java derleyicisinin mesajlarıyla aynıdır.
    
              
    Advanced features such as lambdas, streams, threads and files are not supported. If your program needs them, the console will say so.Lambda, stream, thread ve dosya işlemleri gibi ileri özellikler desteklenmiyor. Programın bunlara ihtiyaç duyarsa konsol bunu söyler.
